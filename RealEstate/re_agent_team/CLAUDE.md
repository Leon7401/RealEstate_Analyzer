# 不動産投資分析システム — 開発指示

## 事業モデル
- 自社建築アパート: 利回り8-9%で建築 → 8年保有 → 売却（利回り6.5-7%で販売）
- 販売価格帯: 1億〜1.5億円。賃料収入が最も高い状態で売却
- CF + 売却益 + 資産性の多角評価が必要

## 技術スタック
- Python 3.14 / FastAPI / SQLite (output/realestate.db)
- Leaflet.js + OpenStreetMap（フロント）
- BaseAgent ABC → 各エージェントが継承、run()実装
- config/settings.py が設定の単一ソース
- .env に REINFOLIB_API_KEY を格納

## スコアリング基準（最重要）

### 駅力・駅距離
- 徒歩10分以内が検討対象（エリア次第で11-12分も可）
- 徒歩13分以上は原則対象外
- 新駅開発・駅前再開発エリアは加点（橋本・村岡新駅・多摩モノレール町田等）

### 敷地面積・地形
- 70㎡以上（建蔽率60%・容積率200%なら木造3F 6戸が可能）
- 整形地 > 不整形地。南北に奥行きある正方形が最良
- 擁壁立地・階段擁壁は例外なく除外
- 接道面の間口6.5m以上（未満だと1層2戸が困難）

### 接道
- 道路種別: 42条1項1号道路 or 2項道路の公道が優先
- 42条2項私道・1項5号道路は所在地とのバランスで判断
- 通行掘削承諾書の取得見込みなしは基本NG
- 前面道路幅員 → 容積率制限の確認必須
- 角地は建蔽率+10%緩和 + 斜線制限緩和で加点
- 北側道路は北側斜線回避で有利

### 斜線制限・日影規制
- 北側斜線: 母屋下がりによるボリューム減。北側道路なら影響少
- 道路斜線: 南北に長い敷地なら影響少
- 日影規制: 同上

### 都市計画
- 建築可能な用途地域: 第一種中高層〜準工業地域。工業専用地域はNG
- 低層住居専用地域でも3F建築可（絶対高さ12m指定・容積率100%以上・70㎡以上・北側道路が条件）
- 建蔽率60%以上、容積率200%以上
- 高度地区3種以上

### ハザード
- 内水・洪水・津波: 浸水2m以内なら検討対象内
- 土砂災害特別警戒区域・家屋倒壊等氾濫想定区域は完全NG

### その他コスト注意
- セットバック前3m未満の道路 → 施工単価増（+0.4万/㎡前後）
- 敷地内電柱移設: トランスあり100万円/なし50万円
- ワンルーム条例（自治体別の最低面積・戸数制限）を確認

## プラン生成ルール
- 第一優先: 3F建て + 20㎡以上1K（1Rは女性に選ばれないためNG）
- 第二優先: 2F建て + 全戸ロフト付 + 20㎡以上1K
- 利回り計算は必ず**総投資額**（土地代+諸費用7%+建築費+付帯費15%）ベース
- 構造別単価: 木造22万/㎡、重量鉄骨30万/㎡

## 標準設備（プランコスト算入）
- 準耐火構造、省エネ等級3級
- セパレート水回り、追焚き、浴室乾燥、独立洗面台
- IH2口、食洗機、宅配BOX、防犯カメラ、高速ネット1G
- ロフト付の場合: 収納付き固定階段ロフト+デスクカウンター
- オートロックは不要（居室が狭くなるため）

## API連携（不動産情報ライブラリ）
ヘッダ: `Ocp-Apim-Subscription-Key: {API_KEY}`

| エンドポイント | 用途 |
|---------------|------|
| `/XIT/V1/GetTransactionPrice` | 周辺取引実績・相場算出 |
| `/XIT/V1/GetPublicLandPrice` | 公示地価推移・値上がり率 |
| `/XIT/V1/GetPrefectureLandPrice` | 基準地価推移 |
| `/XIT/V1/GetZoningMap` | 用途地域の自動取得 |
| `/XIT/V1/GetFloodHazardMap` 等 | 洪水・土砂・津波リスク |
| `/XIT/V1/GetPopulation` | 人口・世帯（エリア需要予測） |
| `/XIT/V1/GetFacilities` | 周辺施設（生活利便性） |

- スクレイピング条件: 土地付き一棟/土地のみ/一棟のみ、所有権必須、区分除外
- コード変更時は既存のBaseAgent継承パターンを踏襲
- settings.py に定数を集約、ハードコード禁止
